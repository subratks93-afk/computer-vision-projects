A real-time **Fire Detection and Protection System** built using **Raspberry Pi**, **Python**, **OpenCV**, and **Computer Vision**. The system continuously monitors the environment through a camera, detects fire using image processing and deep learning techniques, and automatically activates alarms and a fire suppression mechanism.

---

## 📌 Overview

Traditional fire detection systems primarily rely on smoke or heat sensors, which may experience delayed response or false alarms. This project combines **computer vision**, **image processing**, and **environmental sensors** to provide faster, more accurate fire detection and automatic response.

Upon detecting fire, the system can:

- Detect flames in real time using a camera
  
- Trigger a buzzer alarm
  
- Activate an automatic fire suppression mechanism
  
- Display live monitoring through a web dashboard
  
- Send fire alert notifications

## ⚙️ Working

1. The camera continuously captures live video.
   
2. Raspberry Pi processes each frame using OpenCV.
   
3. Fire regions are detected using image processing and CNN classification.
   
4. Smoke and temperature sensor readings are used to improve detection accuracy.
   
5. When fire is detected:
   
   - The buzzer is activated.
     
   - The fire suppression mechanism is triggered.
     
   - A fire alert is displayed on the web dashboard.
     
   - Live monitoring continues until the threat is cleared.
